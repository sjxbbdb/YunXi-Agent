## 构图验收重点

1. YunXi 的人物身份、面部、发型、服装和饰品必须与参考图一致。
2. 人物侧脸位于画面右侧约 70%–90%，朝向画面中部和左侧。
3. 发丝从右侧向画面中部自然延展，覆盖约 38%–70% 区域，但不形成强风效果。
4. 左侧保留约 32%–38% 的深色负空间，供网页叠放人物卡片。
5. 背景从左侧深冷灰、中部石墨蓝灰过渡到右侧烟灰蓝，不是纯黑或紫色渐变。
6. 局部揭示后必须能够看清面部、眼睛、耳饰、发丝和衣领材质。
7. 不出现第二个人物、UI、文字、边框、白底或强烈霓虹装饰。
8. 在 `16:9`、`16:10` 和较窄桌面裁切下，侧脸五官仍位于安全区域。
