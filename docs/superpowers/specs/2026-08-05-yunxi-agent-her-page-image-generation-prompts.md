# YunXi Agent “她”页面生图提示词

生成时间：2026-08-05 00:53:23 +08:00

署名：开发者

## 使用方式

1. 每次生图都附带现有 YunXi 人物参考图。
2. 将“统一角色锁定词”放在对应素材提示词最前方。
3. 将“统一负面提示词”放入生图工具的负面提示区域。
4. 优先生成 PNG 原图，不提前压缩；确认素材后再转换为 WebP/AVIF。

建议参数：

- 参考图权重：`0.8–0.9`
- 图生图重绘强度：`0.25–0.4`
- 风格权重低于人物一致性权重
- 关闭会显著改变五官、年龄和服装的随机风格

## A4 右侧人物侧脸背景
